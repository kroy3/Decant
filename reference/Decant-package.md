# Decant: benchmark-first ambient RNA decontamination

Start with
[`decant()`](https://kroy3.github.io/Decant/reference/decant.md) for
correction,
[`split_droplets()`](https://kroy3.github.io/Decant/reference/split_droplets.md)
/
[`read_10x_counts()`](https://kroy3.github.io/Decant/reference/read_10x_counts.md)
to get real data in, and the `gate_*()` functions to re-derive every
default from ground truth.

# Naive: subtract ambient point estimate, then test condition per gene.

Naive: subtract ambient point estimate, then test condition per gene.

## Usage

``` r
de_naive(sim)
```

## Arguments

- sim:

  output of
  [`simulate_de()`](https://kroy3.github.io/Decant/reference/simulate_de.md).

## Value

per-gene p-values.

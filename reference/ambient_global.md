# Global soup profile: normalised aggregate of the empty-droplet pool.

Global soup profile: normalised aggregate of the empty-droplet pool.

## Usage

``` r
ambient_global(empty)
```

## Arguments

- empty:

  genes x droplets matrix of background counts (dense or sparse), or a
  [`soup_summary()`](https://kroy3.github.io/Decant/reference/soup_summary.md)
  of them.

## Value

length-G probability vector.

# Empirical-Bayes-style shrinkage of per-sample soup profiles.

Empirical-Bayes-style shrinkage of per-sample soup profiles.

## Usage

``` r
pool_soup(empties_total)
```

## Arguments

- empties_total:

  list of genes x droplets matrices, one per sample.

## Value

list with \$pooled (genes x samples) and \$independent (genes x
samples).
